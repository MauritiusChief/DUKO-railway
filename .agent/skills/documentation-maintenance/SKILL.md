# Documentation Maintenance

## 触发

文档本身变化，或代码/配置变化影响使用方式、架构、接口、运维、安全、领域语义时。

## 清单

1. 按 `AGENTS.md` 的事实优先级核对代码、测试、schema 和 `.env.example`；不读取实际 `.env`。
2. 识别读者与归属：入口放根 README，工作约束放 AGENTS，架构/API/运维放 Wiki，领域语义放 context，实施方案放 `wiki/plans/`。
3. 搜索重复、冲突、失效链接和旧名称。
4. 命令必须来自 package scripts 或已核验入口；标明副作用、前置条件和未验证限制。
5. 不复制密钥、真实 URL 参数、客户数据、日志、数据库内容或实际环境值。
6. 执行 Wiki 强制影响检查；必要时同步主题页和计划状态。
7. 检查 Markdown 链接、路径、标题层级和术语一致性。
8. 用 diff 确认只改了需要的文档，并在结果中列出待确认项。
